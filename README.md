# Kasat Virtual College of Education (KVCE) Website

Official production website for **Kasat Virtual College of Education (KVCE)** — *Educating Since 1999*.

KVCE offers 100+ career-focused specialisations in online degrees and diplomas in partnership with reputed, UGC recognised universities across India.

---

## 🏛️ About KVCE
- **Founder**: Kasat Sir (Nandkishor Kasat)
- **Established**: 1999
- **Headquarters / Campuses**: Palghar, Virar, Bhayandar, Maharashtra, India
- **Programmes**: Education, Management, Arts, Commerce, Science, Computer Applications, Law, Diplomas, PG Diplomas

---

## 🚀 Key Website Features
- **Homepage (`/`)**: Hero section, UGC Recognised indicator badges, 5 key benefits strip, university partners, course preview cards, and institutional trust points.
- **About Us (`/about`)**: Legacy since 1999, 4-pillar flexible learning model, and founder profile with direct contact details.
- **Courses (`/courses`)**: Real-time search, category filter pills (*Arts, Commerce, Science, Management, Computer Applications, Law, Diplomas, PG Diplomas*), category cards with profession-specific imagery, and full course directory.
- **Course Detail (`/courses/[slug]`)**: Breadcrumb navigation, sibling course sidebar, specialisations checklist, key programme parameters (*Duration, Eligibility, Mode, UGC Recognized*), and WhatsApp enquiry CTA.
- **University Partners (`/universities`)**: Official directory of 15+ UGC recognised affiliated universities and career advantage highlights.
- **Contact Us (`/contact`)**: Instant WhatsApp integration, phone helplines, email, office addresses, interactive Google Map embed, and scan-to-WhatsApp QR code.

---

## 🛠️ Technology Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router & Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **SEO**: Dynamic `sitemap.xml`, `robots.txt`, Open Graph metadata

---

## 💻 Getting Started Locally

### Prerequisites
- Node.js 18+ (Node 20+ recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build
```bash
npm run build
npm run start
```
